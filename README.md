#NaturalKillerCells_PDAC
Processed data and downstream analysis of IMC and scRNAseq data for the paper: Periductal Fibroblast Density Defines Lymphocyte Exclusion via a CD44-Dependent Stromal Checkpoint in Pancreatic Cancer. This repository includes the R script that will generate Figures 1B-E, 2G, 3A-D, and Supplementary Figures S1-S3, S5-9. The R script will also provide the code to generate values to input into external software (e.g., Excel and GraphPad Prism) for Figures 2C, 2E-F, Supplementary Figure S3, S5-S6. IMC data to be loaded into the Global Environment can be found at doi: 10.5281/zenodo.10582038 scRNAseq data was previously published at doi: 10.1038/s43018-020-00121-4.
